Sistema de Pizzaria em Python

Descrição
Sistema simples desenvolvido em Python para simular pedidos em uma pizzaria, permitindo a escolha do sabor, tamanho da pizza e o cálculo do valor total do pedido.

Objetivo do Projeto:
Projeto acadêmico criado para praticar lógica de programação, controle de fluxo, validação de entradas e estruturas condicionais.

O foco do projeto é demonstrar raciocínio lógico por meio do código.

Funcionamento:
O sistema permite ao usuário:
> Escolher o sabor da pizza (salgada ou doce)
> Escolher o tamanho (P, M ou G)
> Realizar múltiplos pedidos
> Visualizar o valor total ao final do pedido

 linguagem Utilizada:
> Python

Conceitos Aplicados:
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`while`)
- Validação de entrada do usuário
- Variáveis acumuladoras
